# Proposal

## Why

Markdown 与 API 基本信息编辑目前仅保存在组件内，刷新、取消或切换文档会丢失修改。增加本地草稿与离开保护，减少重复编辑。

## What Changes

- 编辑内容防抖保存到当前浏览器，按系统、用户、项目和文档隔离；新文档按目录和类型隔离。
- 重新编辑时用标准弹窗选择恢复、丢弃或暂不编辑；服务端基础内容变化时明确提醒，绝不自动覆盖。草稿状态放在保存按钮旁，离开确认复用项目标准。
- 切换文档、取消编辑和路由离开前提供保留草稿、放弃草稿或继续编辑三项选择；刷新/关闭使用浏览器原生提醒。
- 正式保存成功清理草稿，失败保留；缓存不可用时明确提示。
- 首期覆盖 Markdown 正文/名称及 API 基本信息表单，不含独立 Schema、调试参数和其他弹窗。

## Capabilities

### New Capabilities
- `document-drafts`: 文档编辑的本地恢复和离开保护。

### Modified Capabilities

无。

## Impact

前端两个文档编辑器、共用编辑头、项目页和目录切换入口；新增复用草稿工具及中英文文案。不改变后端接口或数据库，不增加运行依赖。
